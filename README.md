<div align="center"><h2> Overview </h2></div>

**The projects is still in early stages**

This project started as my attempt to create a lightweight alternative to GNU coreutils. After exploring the GNU source code, i felt like i wanted something simper for my own learning and use. The goal is to build small, clear implementations of common Unix utilities using low level system calls.
